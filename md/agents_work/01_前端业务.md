## 1. 架构主线

- **Vue3 `<script setup>` + Composition API**，单一 `useToonflowStore()` 响应式单例驱动全局状态。
- **所有后端请求收口在 `api/toonflow.ts` 的 `ToonflowApi` 类**（HTTP 用 `post/get` 校验统一信封 `ApiEnvelope{code,data,message}`；流式用 `fetch + ReadableStream`）。
- 运行时通过「**编排 → 流式台词 → 语音播放**」三段式 + **预取机制** 实现自动剧情推进。
- 立绘通过 `LayeredAvatar` + `useWebpAvatar` 做 WebP 动画与首帧定格。

## 7. 前端核心业务流程

### 7.1 分层立绘渲染（LayeredAvatar + useWebpAvatar）
`LayeredAvatar.vue` 接收 `foregroundPath`/`backgroundPath`/`firstFramePath`/`animated`/`animationDuration`/`backendDurationMs`(72-99)：
- 背景层 `<img class="layered-avatar__bg" :src="backgroundPath">`；
- PNG 首帧层 `layered-avatar__fg--png`（播放中 hidden）；
- WebP 前景层 `layered-avatar__fg--webp`（播放中显示，定格时 hidden）；
- `effectiveDuration` 优先 `backendDurationMs > animationDuration > 3000`；`emit("animation-end")` 由 `onAnimationEnd` 触发。
- 切角色必须 `reset()` 清 `firstFrameDataUrl`/`isAnimated`，否则串帧。

### 7.2 ScenePlay 对话循环
1. **进入**：`store.startFromWorld` → 无会话则 `initStory`+`introduceStory`(开场白流) → `orchestrateSession`(首章) → `streamSessionPlan`。
2. **用户发言**：`submit()`→`store.sendMessage()`→`performSessionPlayerMessage`(7127)：`addMessage("player", orchestrate:false)`→`continueSessionNarrative`(7662)。
3. **编排**：`resolveSessionOrchestration`(优先预取否则实时 `/game/orchestration`)→`applySessionOrchestrationResult` 生成 NPC/旁白消息。
4. **流式台词**：`streamSessionPlan`(7201) 调 `api.streamDebugLines`，逐行解析 `StreamLinesEvent`：delta→打字机；sentence→分句；done→`commitNarrativeTurn` 回填；error→抛错。
5. **语音播放**：`waitForMessageReveal` 对每条消息逐句 `playMessageAudio`：`resolveMessageVoiceBinding`→`ensureRuntimeCloneBinding`→`resolveRuntimeVoiceUrl`(调 `/game/streamvoice`)→`fetchRuntimeVoiceBlob`→`playRuntimeVoiceBlob`(超时续播)；失败 `replayWithBrowserSpeech`(Web Speech API) 降级。播放中驱动尾部脉冲点。
6. **状态推进**：reveal 完成置 `waiting_player`(可发言)/`waiting_next`(小游戏旁白/敌方回合)；`prefetchOrchestration` 预取下一轮。
7. **小游戏特例**：`activeMiniGame` 走严格串行 `/game/orchestration/minigame`，语音播完后 `miniGameVoiceWaitEnd`(默认 3000ms) 再编排，避免语音被链式中断。
8. **重试/跳过**：编排失败显示「重新编排」(`retryRuntimeMessage` 区分编排失败与发送失败)；`onPlayerSkip` 发 `"."`；`onContinueNarrative` 手动触发。

### 7.3 世界书编辑链路
`SceneCreate`/`ScenePlay`/`SceneHistory` → `WorldBookDialog`(编辑)/`WorldBookViewerDialog`(只读) → 临时 api → 表单编辑 `saveWorldBookEntry` → `importWorldBook`(replace/merge)/`exportJson`。

### 7.4 形象与语音配置链路
- 立绘：`updateAvatarFromFile`(PNG 分离前景/背景)/`updateAvatarFromMp4`(转 GIF+静态背景) → `applyImageToTarget`(AI 生图) → `saveWorldOnly` 持久化。
- 语音：`VoiceBindingDialog` 选 `text/clone/mix/prompt_voice` → `setPlayerVoiceBinding` 等 → `saveWorldOnly`(旁白立即落库)。运行时由 `voiceBinding.ts` 解析驱动 TTS。

### 7.5 存档与「故事已更新」对齐
`SceneHistory` 检测 `item.storyUpdated` → 弹框提供「继续游玩(确定性对齐)/智能对齐(AI 语义)/重新开始」，对应 `continueSessionForWorld`/`alignSessionWithAi`/`deleteSession`+`startFromWorld`。
